INTRODUCTION介 绍

她Amadeus在你的本机世界线上，
醒来。

一个本地优先、单用户的牧濑红莉栖 AI 陪伴项目。
两种核心模式：日常陪伴，与 VN 陪玩。

FEATURE 001

日常陪伴

文本、语音、长期记忆、TTS 与角色动态，一起构成日常的对话。

角色 →
FEATURE 002

VN 陪玩

她观察你选定的游戏窗口，以自己的身份和知识边界读剧情、做选择判断；点击由你来做。

画廊 →
FEATURE 003

长期记忆

你的长期记忆与 VN 剧情状态分开保存；原始截图和完整游戏文本默认不留存。

系统 →
FEATURE 004

本地运行

三层服务都跑在你的电脑上；模型服务商由你自己选择、自己配置。

      PRODUCT获 取 方 式
      开源，自己在本机运行。

      目前没有经过验收的预编译客户端；克隆源码、配置自己的模型服务后启动三层服务。

      git clone https://github.com/PerpperQAQ/Amadeus-Resonance.git
npm ci && npm run dev                      # Frontend :5173
cd service && npm ci && npm run dev       # Node Proxy :3002
cd service/webrtc && python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt && python server.py   # :8001
