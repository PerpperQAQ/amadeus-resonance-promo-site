## 1｜邂逅のプロローグ　Hello, World Line　序章·初见

**标题**：「初次见面。先说好，我不是来陪你闲聊的——好吧，偶尔也可以。」

**短句**：无（让下面的标签卡来介绍她）

**新观众介绍：3 张纸质标签卡**（米白纸色，斜贴在名字旁，可以点）

| 卡片 | 点击后她的字幕 | 表情 |
|---|---|---|
| 「18 岁 · 脑科学研究者」 | 「年龄不是重点。论文才是。」 | `表情_ニヤニヤ` → `表情_普通` |
| 「维克多·孔多利亚大学」 | 「研究方向是记忆。所以记住你这件事，我是专业的。」 | `表情_楽しい00` |
| 「＠channel 重度用户（？）」 | 「……这张卡是谁贴的。撕掉，马上撕掉。」 | `表情_驚き01` → `表情_頰染め` → `表情_むっとする` |

**首次设置「你是谁」**：标签卡点完（自动播放时在 10 s），画面下方滑出一张单独的纸卡，上面写「初次设置 · 你是谁」。卡上只有一个黑方块「本人」，点下去卡片亮琥珀色。

## 2｜同期共鳴のトリニティ　Synchronized Resonance　声与形

**画面**：`cinema/stage-lab.webp`，镜头推到她的半身。下方左边是三个黑方块「字」「声」「形」，右边是四张小纸卡，代表表情预设的四组「日常 / 亲近 / 质疑 / 担忧」。

**标题**：「同一句话，我会写给你、说给你，也会写在脸上。」

**短句**：「中途想插话也行，我会停下来听。」

**角落常驻小注**：「原作语音，演示用｜表情为演示编排」

**互动**

1. **「字」**：只出中文字幕条「把漆原的性别变回男性，IBN5100 就真的能回来吗？」，没有声音；表情 `表情_困る00`。
2. **「声」**：播 `audio/kurisu-crs_2148.m4a`（7.8 s），日中双行字幕，口型跟音量走；表情 `表情_普通` → 3 s 时 `表情_困る01` → 结尾 `表情_睨む`。
3. **「形」**：播 `audio/kurisu-crs_1897.m4a` 的前约 7 s，按逐词时间戳切换 `表情_むっとする` → `表情_睨む（強）` → `表情_驚き01`。
4. **打断**：「声」或「形」正在播的时候，再点一下任意方块，语音立刻停，字幕被截断，她换成新的一条字幕：「嗯？你说。」，表情 `表情_驚き00` → `表情_普通`。这是在演示「语音聊天可以被打断」。
5. **四组表情纸卡**：点一张，她就摆一个该组的代表表情，没有字幕。
   - 日常：`表情_普通`
   - 亲近：`表情_楽しい00`
   - 质疑：`表情_睨む`
   - 担忧：`表情_困る02`
   - 卡片背面印「24 种预设 · 4 组」，这是全片唯一一处数字。

**自动播放**：字（15–18 s）→ 声（18–26 s）→ 形（26–31 s，第 5 s 时自动“打断”，演示被打断的那一下）→ 四张卡快速翻一遍（31–34 s）。

**手动滚走时**：语音立即停，字幕清空。

## 3｜記憶領域のアーカイブ　Memory Archive　记忆

**画面**：镜头拉远，研究所背景加深网点。她旁边立着一个真实感的档案抽屉，用纸卡堆叠来表现（真实纸张质感的图片，不画线框）。下面是三个黑方块：「Mem0」「本地」「关闭」，「Mem0」右上角贴一张小纸条「推荐」。

**标题**：「记住你这件事，你来决定我怎么做。」

**短句**：「你和我的事，与看过的故事，我分两个抽屉放。」

**互动**（她每次都回应同一个问题：用户问「还记得我上次说的吗？」，这句以灰色用户字幕条出现）

| 按钮 | 她的字幕 | 表情 | 画面 |
|---|---|---|---|
| Mem0 | 「当然。你说考试周要熬夜——所以今天睡够了没有？」 | `表情_ニヤニヤ` → `表情_困る01` | 抽屉拉开，一张纸卡飞到她手边 |
| 本地 | 「记得。放在你这台电脑里，哪儿也没去。」 | `表情_普通` → `表情_楽しい00` | 同一张卡，落进一个画面内的本地小盒子 |
| 关闭 | 「这次我不记。不过现在这一段，我还是会认真听。」 | `表情_困る00` → `表情_普通` | 抽屉合上，纸卡变成空白 |

**附加小互动「拔掉」**：选 Mem0 时，档案抽屉上会出现一个小黑方块「⏏ 断开」，模拟记忆服务挂掉。点下去：
- 她的字幕：「……记忆那边好像断线了。没关系，先接着聊。」
- 表情：`表情_驚き00` → `表情_普通`
- 这是在演示「记忆服务失败时她照常对话」。不显示任何报错框。

**两个抽屉**：抽屉正面有两张标签纸「你和我」「看过的故事」。点「看过的故事」时她说：「那是剧情，不是你的经历。别想让我记混。」，表情 `表情_むっとする`（轻）。

**自动播放**：Mem0（35–39 s）→ 本地（39–42 s）→ 关闭（42–45 s）→ 回到 Mem0，再按「⏏ 断开」（45–48 s）→ 两个抽屉标签闪一下（48–50 s）。

**素材**：研究所背景；抽屉和纸卡用真实照片抠图 *（待找：可商用的档案柜或卡片抽屉照片，或者用本地纸张素材合成）*。

## 4｜既視感のオブザーバー　Déjà-vu Observer　一起看

**画面**：镜头从她肩后越过，看向左侧约 60% 的「游戏画面」（`cinema/mem-lab.webp`，有过去的她）。右侧是浮窗尺度的她，构图参考真实浮窗截图 `reboot/app-overlay.webp`。

**标题**：「你玩，我看。偶尔多嘴一句。」

**短句**：「选项是你的。我只负责说出我的看法。」

**停点 0：选窗口**（34 s 前后的开场）
- 屏幕上先摆三张真实缩略图纸卡：游戏窗口、浏览器、编辑器。
- 点游戏那张，镜头推进去。
- 她的字幕：「就这个？好，我看着。」

**停点一：既视感**
- 游戏画面里出现过去的她，红蓝错位加强 0.5 s。
- 她先静止 1.2 s，然后视线移向画面。表情 `表情_驚き00`（低强度）→ `表情_困る01`。
- 字幕：「……说不上来，总觉得在哪见过。」
- 新观众此时可以点画面上的小黑方块「?」，她解释一句：「后面的剧情我也不知道。我只知道我亲身经历过的。」这句在演示知识边界和不剧透。

**停点二：建议卡**
- 底部出现两张黑卡：「A 先去研究所」「B 留下来问清楚」（选项文字是我们自拟的）。
- 她的字幕：「换成我，会选 B。……干嘛看我，按的人又不是我。」表情 `表情_ニヤニヤ`（轻）。
- 用户点 B 后，卡片亮琥珀色；她说「嗯，不坏。」，表情 `表情_照れる` 闪 0.6 s → `表情_普通`。
- 如果用户点 A：她说「也行。看看会怎样。」，表情 `表情_楽しい00`。

**自动播放**：选窗口（50–53 s）→ 既视感（53–60 s，「?」自动点一次）→ 建议卡（60–67 s，66 s 时自动点 B）→ 拉远（67–70 s）。

**音频**：无。

## 5｜沈黙律のエピグラフ　Silent Epigraph　分寸

**画面**：继续用游戏画面，换一张有其他角色正在说话的 CG *（待核：`mem-radiokan` / `mem-rooftop`，没有合适的就沿用第 4 段的图）*。游戏台词用灰底字幕条，跟她的黑底字幕条区分开。

**标题**：「别人说话的时候，我会等。」

**短句**：无

**互动：五张叠起来的胶片格**（用真实 CG 裁出的五格，横排放在画面底部，是真实图片，不是滑杆）。每格角上贴一个小字：「静」「表情」「字幕」「开口」「判断」。点哪一格，她就用那一级回应同一句游戏台词。

| 格 | 她的反应 |
|---|---|
| 静 | 不动、不出字幕，画面上只有游戏台词。最显眼的一格，默认高亮 |
| 表情 | 只挑一下眉：`表情_睨む`（低强度 1.5 s）→ `表情_普通` |
| 字幕 | 只出字幕：「……嗯。」 |
| 开口 | 等游戏台词结束 0.8 s 后才开口：「这人说话总绕弯子。」，表情 `表情_ニヤニヤ`。没有语音，只有字幕，因为我们没有她这句的配音，不伪造音频 |
| 判断 | 「如果到了选项，我会提醒你。现在不用。」，表情 `表情_普通` |

**自动播放**：按 静 → 表情 → 字幕 → 开口 依次点（70–78 s），最后回到「静」并停 1 s（78–80 s）。「判断」格只在手动时可点。

## 与 v1 相比改了什么
- 删掉了「你不是冈部」「共同观测者」和开场的「不是记忆副本 / 不是 Amadeus」否定句，全片不定义用户身份；首次设置只露出「本人」一个按钮，不提别的身份。
- 全部改成红莉栖第一人称，语气里带一点小吐槽。
- 第 1 段新增角色页式介绍：大名字配注音、CV 一行、3 张可点的标签卡，她对每张卡都有反应。
- 新增第 3 段「记忆」：三种模式的按钮、断开记忆服务、两个分开的抽屉。原来的「分寸」段就不再顺带讲记忆。
- 第 2 段加了打断演示和四组表情纸卡；第 4 段加了选窗口和「?」知识边界；第 5 段用五格胶片表现五级输出；第 6 段用索引卡加印章表现配置控制台。
- 时长从约 82 s 变成约 88 s。
