> 状态：草稿，待 Owner 审。交互沿用 spatial.html：一个固定舞台、一条时间轴，滚动位置就是播放头（progress 0→6），右上「播放 PV」自动走完全程（约 80 s），一滚轮就暂停交还控制。

> 诚实边界：不写「可下载 / 开源」「已支持 RE:BOOT」「AI 自动选对表情」；原作语音一律标「原作语音，演示用」。

每段内部都是「镜头推进 → 停顿（停点，文案出现）→ 镜头离开」。停点占每段约 40%，滚动时文案用黑条解密方式出场，英文章节名从 0/1 乱码解码。

## 舞台三层（spatial 三明治结构）

- 后层：场景 CG（每段一张，镜头在里面推拉平移；段与段之间交叉淡化，不硬切）
- 中层：E-mote 红莉栖 `public/models/kurisu_ab.expressions.psb`（外套）。第 5 段换成 `kurisu_ab_labcoat.expressions.psb`（白大褂），可选。模型加载失败时用 `public/img/fallback-kurisu.webp`
- 前层：真实物件抠图（`public/img/props/*.webp`），放大速度比后层快，挡住她一部分，形成景深

表情名一律取自 `public/models/kurisu_ab-catalog.json` 的 authoredExpressions，全部手工编排时间线。

## 1｜PROLOGUE　序章 — 她是谁（0.0–1.0，0–12 s）

- 背景：0–4 s 透明 Logo 开场，黑底；4–12 s 底图 `public/img/boot-cg.webp`（Ready 界面的红莉栖近景 CG），带网点和轻微红蓝错位
- Logo：`public/img/logo-base.webp` + `logo-gear-major.webp` + `logo-gear-minor.webp`，齿轮转半圈后整体淡出（开场等首屏图和模型加载完，再一次性亮相，学 RE:BOOT）
- 镜头：从 CG 的全景（她占画面约 30%）慢推到胸像构图，后层放大 1.00→1.12，略往右偏
- 模型：4 s 起淡入，站右三分之一线；`表情_普通` → 8 s 起 `表情_ニヤニヤ`（停留 2 s）→ 回 `表情_普通`
- 标题（字幕条，两行依次解密）：
  - 「不是记忆副本，是活着的那个她。」　「她」注音 **Amadeus**
  - 「你不是冈部，她知道。」　「你」注音 **共同观测者**
- 短句：无
- 小注：无
- 交互：无。首屏右下只有一个黑方块「▶ 播放 PV」
- 音频：静音（全片没有 BGM，素材清单尚无授权音乐）
- 转场：CG 往左滑出，研究所背景从右侧接入，镜头仿佛横移进实验室

## 2｜VOICE　声与形 — 一句话，三种表达（1.0–2.6，12–34 s）重头段

- 背景：`public/img/cinema/stage-lab.webp`（滚动中途换成 `stage-lab-obs.webp` 的网点版，表示「进入观测」）
- 镜头：1.0–1.3 从研究所全景推到她的半身（她居中偏右，占画面高度约 85%）；停点 1.3–2.4 不动，只有 1.5% 的呼吸缩放；2.4–2.6 拉远
- 停点上方是标题，下方三个黑色小方块按钮：「字」「声」「形」
- 标题：「一句话，三种表达。」　「表达」注音 **同一个判断**
- 短句：「中文字幕、日语语音、表情，落在同一个节拍上。」
- 小注（固定在角落，播放时一直显示）：「原作语音，演示用｜表情为手工编排」

交互（自动播放时按 字→声→形 依次自动触发；滚动停在这里时由用户点按）：
1. 「字」（约 15–19 s）：只出中文字幕条「把漆原的性别变回男性，IBN5100 就真的能回来吗？」，模型 `表情_困る00`，视线略向下，没有声音
2. 「声」（约 19–27 s）：播放 `public/audio/kurisu-crs_2148.m4a`（7.8 s），日中双行字幕，口型跟随音量；表情 `表情_普通` → 3 s 时 `表情_困る01` → 结尾 `表情_睨む`
3. 「形」（约 27–34 s，自动播放时只播前约 7 s）：播放 `public/audio/kurisu-crs_1897.m4a`（16.1 s，「極端な管理社会。全体主義。……」），按逐词时间戳切换：`表情_むっとする` → `表情_睨む（強）` → 说到真由理时 `表情_驚き01` → `表情_困る02`。头部倾斜、视线跟着变（catalog 参数 `head_slant`、`head_LR`）
- 用户手动滚动离开时：语音立即停止，字幕清空（「迟到不补演」）
- 转场：她的视线往左下移，镜头沿着视线横摇，同时研究所淡化成游戏画面

## 3｜OBSERVER　共同观测者 — 一起看 VN（2.6–4.2，34–56 s）重头段

- 背景（游戏窗口场景）：用「真实应用截图 + 原作 CG」拼成，不画框。
  - 画面左侧约 60%：一张原作 CG 当作「游戏画面」，优先用 `public/img/cinema/mem-lab.webp`，它正好有过去的她；网点版是 `mem-lab-obs.webp`
  - 右侧：E-mote 模型以浮窗尺度出现，与真实浮窗截图 `public/img/reboot/app-overlay.webp` 的构图一致
- 镜头：2.6–3.0 从她的肩后越过，推向左侧的「游戏画面」（像和她一起看）；3.0–3.6 停点一；3.6–3.8 往下移；3.8–4.2 停点二
- 停点一，既视感（34–44 s）：
  - 游戏画面里出现过去的红莉栖（`mem-lab-obs.webp` 的红蓝错位加强一档，持续 0.5 s）
  - 模型：先完全静止 1.2 s（不说话、不换表情）→ 视线移向画面（`face_eye_LR` 左偏）→ `表情_驚き00` 低强度 → `表情_困る01n`
  - 字幕条（不出声，只有字幕）：「……说不上来，总觉得在哪见过。」
  - 标题：「她也会不确定。」　「不确定」注音 **既视感**
- 停点二，选择（44–56 s）：
  - 画面：底部出现两张黑色选项卡（纯黑方块 + 白字，借 RE:BOOT 按钮语言，不画游戏 UI 框），选项文字自拟、不用原作台词：「A 先去研究所」「B 留下来问清楚」
  - 模型：`表情_普通` → `表情_ニヤニヤ`（轻）；字幕：「如果是我，我会选 B。不过——按键的是你。」
  - 用户真点一下 B（自动播放时 52 s 时自动点），卡片亮起琥珀色；模型 `表情_照れる` 闪 0.6 s 后回 `表情_普通`
  - 标题：「能做到，但选择不做。」　「做」注音 **替你点**
  - 小注：「她只给建议，按键永远在你手上。」
- 音频：无（VN 段刻意不放她的语音，为下一段的「让路」做铺垫）
- 转场：游戏画面变暗，镜头往后拉

## 4｜RESTRAINT　分寸 — 沉默，也是表演（4.2–5.0，56–66 s）

- 标题：「游戏在说话时，她不抢。」　「不抢」注音 **沉默**
- 短句：「看过的故事，不会被记成你的经历。」
- 音频：无（没有可用的其他角色原声；只用字幕表示游戏在说话，不伪造音频）
- 转场：画面网点逐渐加重直到变成纯色块，切到神社
