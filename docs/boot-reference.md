# 开屏对照：用户 Amadeus 前端 vs 本页（第四轮修正）

## 1. 取证方式（如实说明）
- 用 Mac 上的 Chrome + Playwright 打开 `http://127.0.0.1:5195/?s=ready&bare`，**刷新后不点击不按键**，用 CDP `Page.screencast` 连续抓取（约 50 帧/秒，文件名带毫秒时间戳），再按 125ms 间隔抽帧成对照表实际查看（`.tmp/ref2/s1–s5.jpg`）；随后悬停“接入”入口抓字符解码，按 Enter 抓转场（`h1.jpg`、`e1.jpg`、`e2.jpg`）。
- 源码来自其真实目录（`…/amadeus-resonance-frontend-claude-20260925/src`，只读）：`design/WorldlineShift.jsx`、`design/Worldlines.jsx`、`styles/worldline.css`、`styles/ready.css`、`screens/Ready.jsx`、`design/IbmMark.jsx`，以及数字字形库 `design-assets/divergence-meter/meterLib.js`。
- 前 ~1.8s 抓到的是页面刷新时上一次 Daily 界面残影 + 白/黑闪（`?s=ready` 跳转造成），**不属于其开屏表演**，本页不模仿。

## 2. 其开屏（WorldlineShift，约 4.9s）的逐阶段结构
| 时间 | 阶段 | 元素 / 参数（源码 + 帧） |
|---|---|---|
| 0.0 | 压暗转红 | 底图 = 红莉栖近景 CG，`brightness(.28) saturate(.35) sepia(.5) hue-rotate(-18deg)` + 椭圆暗角；0.5s 淡入 |
| 0.05 | 红色光带 | 6 条 `2.2cqh` 高的**模糊横带**（`blur(3px)`，渐变 rgba(200,40,20,.55)→rgba(255,90,40,.25)，`mix-blend-mode:screen`），位置 12/26/44/63/80/91%，各自 1.1–1.9s 左右漂移 ±20% |
| 0.25 | 大读数入场 | 满屏（宽 78%）**橙色细线数字**，**没有玻璃管/金属壳**；入场 `scale 2.4 + blur 10px → 1`，1.3s `power3.out` |
| 0.6 | 二进制 | 14 行 `Barlow Condensed` 米白 .35 透明度二进制串，缓慢向左飘 |
| 0.7 | 整排成组跳变 | 每 **260ms** 换一整排值（`1.130426 → 3.352468 → 0.029135 → 7.776802 → 9.578024 → 0.571024 …`），换值瞬间 70ms **flash**（外晕加粗）；跳变中每位带暗的「+」支撑与两个残影字 |
| 0.9 | 方程 | 4 条 `Caveat` 手写体方程（`#e0502a`，发光 `0 0 1.2cqh`），0.2s 错开从左/右划入，透明度 .62→ |
| 2.35 | 逐位收束 | 每位间隔 **110ms** 由左到右锁定为 `1.048596`（锁定位 flash 150ms，残影/「+」撑退去只留干净数字），未锁定位每 55ms 乱跳 |
| 1.2–3.6 | 世界线 | 一束线从上方竖直流下 → 拐过左下角 → 沿底边向右延伸；之后收拢成一束，最终接上 Ready 底边那条线 |
| 3.1 | 闪光 | 全屏 `#fff4e0`、`overlay` 混合，0.08s 到 .8，0.55s 退去 |
| 3.9 | 淡出 | 数字 `scale .96` 淡出 0.9s，方程/二进制/光带 0.6s 淡出；4.05 起揭开 Ready，红色罩 0.9s 退去 |
| Ready | 入口 | Ready.jsx：入口按钮用 **El Psy Kongroo × IBM 5100 解码**（`APL386 Unicode` 字体，APL 乱码逐位解码），说明文字写成 APL 注释，就绪后提示 `⍝ PRESS ENTER`；Enter 进入 Daily（悬停/Enter 的帧见 `.tmp/ref2/h1.jpg`、`e1.jpg`、`e2.jpg`） |

### 数字（辉光管内部）的画法
字形是**弯曲单线**（0–9 的 SVG path，附一条十字「+」支撑），每个数字叠四层：
`z0` #ff4a00 宽 18 opacity .5 高斯模糊 9；`z1` #ff7a10 宽 7 opacity .85 模糊 2.4；`z2` #ffb040 宽 3.6；`z3` #fff0c0 宽 1.3；flash 时 `z0` 宽 30 opacity .9。未点亮的残影字 `#b8561c` 宽 1.3 opacity .32。小数点 = 橙色模糊圆 + 浅黄芯，占一个独立位置，共 8 个位置（pitch 146，字形放大 1.35）。

| Enter/悬停入口 | Ready 页面入口的 El Psy Kongroo × IBM 5100 解码 | 本页没有 Ready 入口页，不做 | 本页开屏直接进入首屏 |

## 4. 世界线变动彩蛋同步简化（用户反馈）
彩蛋沿用同一套语言：短促失稳（轻微色散 + 抖动）→ 压暗转红 + 红色光带 → **橙色细线数字**整排成组跳变（只有数字，无玻璃管）→ 逐位锁定 → 闪光 → 黑场换世界线 → 文字从 IBM 5100 乱码重组；约 3 秒。移除了变体、青色长波、人像/符号蒙太奇、大量整页滤镜。结尾章的读数仪也换成同一套数字（不再用 GN-4 实拍图）。


## 第六轮：进入按钮（对照用户 Ready 入口）
- 参照：`design/IbmMark.jsx`（平时 APL 乱码、偶尔一位在变；悬停/聚焦逐位 `90+i*42ms` 锁定成台词；说明文字写成 APL 注释；`PRESS ENTER` 提示）与 `worldline.css` 的 `.ib*`（`APL386 Unicode`/`IBM Plex Mono`、字符格宽 .76em、锁定后浅橙发光）。
- 本页实现（`src/entry.js`）：字符池 = APL 基本符号 50% + 叠打字符 18% + 十六进制 20% + `$#%&*@+=<>` 12%（IBM 5100 时代：BASIC/APL/HEX）；按钮下方还有两行“代码”（BASIC `PEEK` 行 / 十六进制 + APL），缓慢变化；悬停时代码行变暗。台词用 “El Psy Kongroo”（14 格，空格显示为 `·`）。
- 状态：`loading`（乱码 90ms 快速刷新、不可点、注释 `⍝ LOADING nn% · 0x....`）→ `ready`（乱码 420ms 偶尔一位变化，可点，`⍝ PRESS ENTER`）→ `offline`（模型加载失败/超时：`⍝ MODEL.OFFLINE · STATIC.IMAGE`，仍可进入）。
- 与用户 Ready 的差异：用户页底部入口是一条小字，这里按需求放在世界线汇聚点正下方并加了代码行；点击转场用一次闪光 + 整屏淡出（约 0.9s），比用户 Enter→Daily 的转场更简单。

## 第六轮：开屏背景（极简重做）
- 不再使用秋叶原街景照片。`src/bgfield.js`，canvas 单层：① 深黑偏冷底色 + 极缓呼吸的中心暗光，叠极淡的星图（细密点阵、以汇聚点为圆心的 5 圈细环 + 刻度 + 十字准线）；② 4–6 列极淡的 IBM 5100 风格代码（十六进制 / APL / BASIC 行，其中每 3 列取一列琥珀色）缓慢纵向漂移；③ 世界线汇聚时汇聚点处逐渐亮起一团很淡的暖光（`setWarm`），点击进入时随整个开屏淡出。
- 静态的星图与代码列预渲染到离屏画布，每帧只平移/混合；页面不可见时暂停（visibilitychange）。胶片噪点与 CRT 扫描线只保留极轻的 CSS 扫描线。已去掉：照片底图、方程、二进制串、红色光带在数字阶段之后的残留。


## 开屏世界线（第六轮复核后重做 · `src/wconv.js`）
用户要求：5–7 条互相独立的世界线、各自不同起点与路径、极细线串着大小不一的发光节点（星图 / 地铁线路风格）、错开时间点亮、逐条汇入同一点且每次汇入亮闪。复核结论：此前版本是 16 条同起点的线束同时生长、没有逐条汇入的闪光，**不符合**，已重做：
- 6 条线，起点分布在左上区域的上缘与左缘（7 个预设起点取 6 个），各自独立的三次贝塞尔路径 + 各自缓慢的垂向游移（两种频率叠加，相位/幅度/速度各异）。
- 线宽 0.6–0.9px；每条 5–8 个节点，半径 0.9–6.3px（幂次分布，少数大星、多数微尘），线头经过时依次亮起并有一次放大辉光，之后缓慢呼吸并沿线微漂。
- 出发时刻错开（顺序与空间位置无关），整体进度 `grow` 由开屏流动阶段 3.6s 线性推进。
- 每条线头抵达汇集点时：汇集点亮斑瞬时增亮（衰减约 0.28s）+ 一圈扩散环；汇集点随抵达数累积变亮；全部抵达后随模型就绪度 `setGlow` 继续亮到就绪。
- 与之前一致：不使用橙色粗曲线；颜色取橙/杏/浅金系，与橙色数字协调。截图：`docs/screenshots/r6/boot-wl-sheet.jpg`（每 450ms 一帧）、`boot-wl-full-3300.jpg`。

## 第七轮：CG 开屏的世界线增强（并行播放 / 汇聚后动态 / logo / 层次）
