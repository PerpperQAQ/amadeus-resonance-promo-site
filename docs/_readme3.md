
## 第三轮更新（世界线演出重做）

- **底图调色**：保留各章原图的色彩倾向（夜蓝 / 街招 / 暖黄实验室），只做统一的压暗、暗角、颗粒与极淡的暖调/琥珀高光（`scripts/build-images.py`，A/B 两个世界线各一套）。
- **开场**（`src/boot.js`）：参照用户 Amadeus 项目的世界线变动演出（节奏与元素，代码自写）——暗场、满屏大号细线读数整排跳变、红橙光带、方程/二进制、一束世界线从上方汇向左下角再沿底边生长、读数逐位锁定到 1.048596、闪光淡出。**世界线生长与读数锁定由 E‑mote 加载进度驱动**；未就绪时点击只加速；失败/超时降级静态图并仍结束。
- **指针**（`src/cursor.js`）：机械齿轮指针，近乎即时跟随，无拖尾；移动时按速度旋转，悬停放大加速并出现刻度环，点击“咬合”一个齿距并泛起涟漪。模块独立，可整体替换。
- **人物换场**（`src/stagefx.js`）：8 种（滑入视差 / 色散硬切 / 推近特写 / 自下升起 / 远景淡入 / 圆形光圈 / 辉光管翻页式 / 边缘探头），各章 2–3 种候选且不与上次重复；Web Animations，不增加 WebGL 负担，重复触发令牌防抖。
- **世界线束**（`src/strands.js`）：一束细线（Canvas 2D）。用于进度条（`src/rail.js`）、开场、世界线变动。
- **世界线变动**（`src/shift.js`）：横穿画面的世界线束 + 负片闪 + 波纹环 + 满屏大读数跳变 + IBM 5100 乱码/解码 + Logo 齿轮倒转。
- **Logo**：字标图层始终位于齿轮之上（与原 logo 的叠放关系一致），旋转不遮挡文字。
- 调研文档：`docs/worldline-reference.md`（世界线演出参考）、`docs/props-candidates.md`（道具素材候选，素材在 `assets-candidates/`，**尚未替换页面里的自绘道具**）。
- 无头验证：`node scripts/e2e.mjs`（默认使用真实 GPU；`SOFT=1` 软件渲染）；开场/换场/变动帧采集：`scripts/cap-boot.mjs`、`scripts/cap-misc.mjs`。
