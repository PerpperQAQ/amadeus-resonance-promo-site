
## 5. 实看视频关键帧（第四轮）

用户提供了原作片段《【命运石之门片段】世界线六次变动片段截取.mp4》（1280×720，约 8 分钟）。先由视频模型生成了一份分析（`/workspace/worldline-video-analysis.md`），我再用 ffmpeg 在 Mac 上按其时间点（00:04–00:12、00:22–00:32、00:40–00:47、00:53–00:59、01:10–01:15、01:21–01:28）每 0.25 s 抽帧到项目 `.tmp/wl-frames/`（**仅本地工作文件，不进工程交付/dist**），并亲自看了 6 张联系表（`sheet1–6.jpg`）与 3 张放大帧。结论以实看为准：

**与模型分析一致的**
- 触发：手机（红色翻盖/发送完成）特写 → **白光过曝**把画面吞没；之后是人物近景的**去饱和/偏青绿的反相色**、强烈模糊与拖影（烟雾般的重影），第 3 次出现闪电与**人物液化扭曲**，第 5 次**极度推近到瞳孔**、数字叠在瞳孔上，第 6 次出现“融化”与噪点。
- **蓝色交织正弦（示波器）波纹**确实存在，叠在深蓝/黑底和模糊人影上，第 1、2、3、6 次明显，第 5 次没有。
- 辉光管：8 位、固定小数点、**橙红偏亮黄的细线字形**、金属网格底板、玻璃管边；数值**随机快速跳变**（如 1.905006 → 0.805871 → 1.609757…），带**强烈散焦/横向与纵向动态模糊 + 重影**；最后**卡定**在目标值（0.571024 / 0.571015 / 0.523299 / 0.409420 / 0.337187）。落定后下一帧是**横向拖影的橙色光带**，随后**硬切黑场**。
- 视频上方橙色“世界线变动率：a→b”字幕是搬运者加的，非原作画面（本页不使用）。

**需要修正的（实看不同）**
1. **白场不是“0.1 s 内闪一下”**，而是约 1–1.5 s 的**持续过曝洗白**（画面逐渐被白光吞掉、人物发白），并非高频硬闪（高频黑白闪仅在第 4 次）。
2. **蓝色波纹不是主体**，只是辉光管出现前约 0.5–1 s 的“过门”；多数时间是**去饱和的模糊场景 + 噪点**，辉光管数字是叠在这个模糊场景上的（并非总在纯黑背景上）；纯黑底只出现在卡定之后。
3. 辉光管**一开始很大、很糊（散焦）**，随后变清晰；各位**几乎同时卡定**（不是严格从左到右）。落定后有短暂的发光峰值，然后被横向拖影吞掉。
4. “垂直老虎机式滚动”不太准确：看到的主要是**数值整体随机跳变 + 运动模糊**，不是每位竖向滚动条。
5. 没有时钟/齿轮元素（与模型分析一致）；本页 logo 齿轮保持原有设计，不在世界线变动里使用。

**据此的实现（`src/shift.js`、`src/waves.js`、`src/tube.js`）**
`叮 + 门灯闪` → 白场过曝洗白(≈0.45 s，文字在白光里崩成 IBM 5100 乱码) → 白光退去，**偏青负片闪烁 + RGB 色散 + 液化扭曲(SVG feDisplacementMap) + 镜头抖动** → **深蓝黑异空间 + 交织蓝色正弦示波器波纹**，IBM 5100 屏幕亮起解码 → **8 位辉光管**从散焦放大逐渐清晰，高速随机跳变（模糊/重影），约 2 s 后逐位卡定、亮度峰值 → **横向拖影闪过 → 黑场硬切**，此刻换世界线配色/背景/人物模型 → 黑场淡出，文字逐行从乱码重组。世界线进度条、开屏也采用同一语言：**蓝色交织正弦线束 + 一条琥珀亮线**，辉光管用橙红/亮黄芯 + 玻璃管 + 金属网格。限制：这是对原作演出的**风格致敬**，不是逐帧复刻；没有使用原作视频帧作为素材。
