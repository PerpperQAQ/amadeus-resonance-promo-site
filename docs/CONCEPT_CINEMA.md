# 概念稿：剧场（cinema.html）与左右分栏（split.html）

预览级，只为判断方向，未打磨。分支 `concept/terminal`，dev：`npx vite --host 127.0.0.1 --port 5291 --strictPort`。

共同规则：不画任何线框 / 刻度 / 网格 / HUD / 假日志 / 贴纸 / 跑马灯；每屏一句标题 + 至多一句小字，细节点了才出现；画面由 E-mote 模型 + 官方原画承担；字体只用 AR Serif + AR Sans；动效只有原画推拉 / 交叉淡化、视差、模型机位。`?wl=b` 或 D 键 = B 世界线（换白大褂模型 + 画面淡紫）。滚轮 / ↑↓ 切章。

## A. cinema.html —— 电影画幅
- 上下黑边（约 2.1:1）。上边：名字、章节（序 / 记忆 / 表演）、「开发中」；下边：她的台词当字幕。
- 序：右侧 SG0 主视觉大裁切（渐隐到黑），模型全身站在前面，左下标志 + 标题。
- 记忆：点一张记忆片段 → 左侧显影成大画面，她看向被点的片段、换表情、说一句；“另一条世界线”永远是模糊的（知识边界：没经历过的不编）。机位推近到半身。
- 切章 = 黑边合拢到全黑再打开（切镜），模型从稍远处推上来。D 键世界线也用同样的切镜。
- 表演：字 / 声 / 形（复用 perform.js），字幕在下黑边。

## B. split.html —— 左右分栏（参考 steinsgate0-anime.com 的版式比例）
- 左 45% 素白纸面：大标志 + 一句话；最左一列黑色方键（目录 / 世界线 α·β / 声音）。
- 右 55% 舞台：原画 + 模型合成一张画。切章时原画交叉淡化、模型换位置 / 机位 / 表情；左侧只换一句标题，记忆片段与字声形放在标题下方。
- 记忆屏未选时舞台是去色的屋顶图；点片段后舞台换成该片段原画。

截图：`docs/screenshots/concept-cinema/`、`docs/screenshots/concept-split/`（`a-` = A 世界线，`b-` = B）。
脚本：`node scripts/cap-cinema.mjs <dir> <w> <h> [--b] [--full]`，`scripts/cap-split.mjs` 同。

已知问题 / 待定：
- 所有官方原画为 official_reference_only，公开前必须替换（见 ASSETS.md）。
- cinema 序屏标志是黑字白边设计，压在暗底上偏闷；split 的纸面上更合适。
- 模型与原画之间没有做光色匹配（预览级）。

## cinema v2（用户选定方向；借 RE:BOOT 宣传页的视觉语言）
- 标题改为黑底字幕条：每行一个紧贴的黑块，压在原画上。
- ruby 双关：她→Amadeus、本机→世界线、记得→观测、形→演出（`<ruby>`，注音绝对定位，不撑宽底字）。
- 原画 / 记忆片段换成烘焙好的 `*-obs.webp`：RGB 错位 + 细网点，像被重新拍下的画面。
- 章节名：Rubik Distressed 做旧英文 + 拉开字距的中文小字（序 章 / 记 忆 / 演 出）。
- 字 / 声 / 形按钮：小黑块 + 青 / 品红细错位阴影。
- 修正：标志在暗底上反相；模型加轻微暖调 + 落地阴影（B 为淡紫边光），原画略降饱和。
- 交互 / 导航结构保持原样（等交互方案）。截图：`docs/screenshots/concept-cinema-v2/`。

## cinema v3：交互逻辑（参考 RE:BOOT 宣传页的逻辑，自写代码，不用 GSAP / Swiper）
- 加载器：暗屏 + 转动的齿轮（`img/logo-gear-major.webp`）；等首屏原画解码 + E-mote 就绪（12 s 兜底，至少 0.5 s）→ `body[data-loaded]` → 整页一次淡入。
- 导航：只有右上角两个黑块（目录 / 世界线 α·β）。首屏内跟随页面，滚过首屏后固定。目录 = 全屏暗色浮层，两列“做旧英文 + 小号中文”；点击 = 关闭 + 平滑滚到该章；Esc 关闭并把焦点还给按钮；打开时 `main` 设为 inert，Tab 焦点在浮层内循环。滚过首屏后右下角出现回到顶部。
- 入场只有两种（IntersectionObserver，各只触发一次）：(a) 标题字幕条与她的台词：黑块先展开、再退去露出文字，按行错开；(b) 英文章节名从 0/1 乱码解码成单词（可见后约 0.4 s 开始，时长按字母数）。
- 原生滚动，无整屏吸附；首屏原画随滚动以约 0.32 倍速度视差（缓动跟随）。
- 模型：章节可见度过半时移到该章位置并换机位（序 = 全身 / 记忆 = 半身 / 她 = 七分身）。
- 记忆 = 画廊：两张大图交叉淡化 0.6 s + 缩略图条；选中后她看向缩略图、换表情、说一句；第 4 张始终模糊。
- 她（KURISU）：模型左，标题右，下面一排状态缩略图（平静 / 得意 / 害羞 / 惊讶 / 生气 / 开心 / 疑问·原声 / 论述·原声）+ 前后箭头。缩略图是用模型本身渲染后截的脸（`scripts/cap-cinema-stills.mjs` → `public/img/cinema/ex-*.webp`）。点击：章节顶部平滑滚入视口，切表情 / 动作，台词黑块入场；两个“原声”状态走 perform.js（原声 + 口型 + 日中字幕）。
- 世界线：右上角按钮或 D 键；减少动态效果时跳过乱码与遮罩，直接显示文字。
- 自检：`node scripts/cap-cinema.mjs <dir> <w> <h> [--b]`（22 项检查 + 截图），截图在 `docs/screenshots/concept-cinema-v3/`。
