# 文案与字体/版式修订（第九轮）

事实依据不变（来自项目文档）：本地优先、单用户、自行配置、双模式、知识边界四层、统一表演、三层本地服务、阶段路线。**未完成能力仍标注“设计目标 / 开发中 / 规划中”**，没有新增任何能力描述。修订只改措辞：更口语、更有画面感，去掉“说明书式、排比、堆砌术语”。

## 一、字体系统
| 用途 | 字体 | 许可 | 说明 |
|---|---|---|---|
| 标题 / 大字 / 条目标题 | **ZCOOL XiaoWei（站酷小薇体）** | SIL OFL 1.1（github.com/google/fonts/ofl/zcoolxiaowei） | 文艺、克制的宋系展示体，细笔画 + 极轻描边（`-webkit-text-stroke:.5px`）补足字重；`ar-disp.woff2`（303KB，子集化） |
| 重点词（`em`） | Noto Serif SC Black（原有） | OFL | 粗宋与细体标题形成强对比，橙色点亮 |
| 正文 | Noto Sans SC 400–500（原有） | OFL | 颜色降到 70–80% 亮度，字距 .04em，行高 1.65–1.9 |
| 编号 / 页码 | 开屏同款辉光管数字（`GlowNum`，字形来自 `meter.js`） | 自绘（字形取自用户项目） | 橙色发光细线，四层辉光，无玻璃管/金属壳；轻微闪烁；换页时短促乱跳后落定 |
| 标注 | Barlow Condensed / Share Tech Mono（原有） | OFL | 仅用于小标注（如 `certain_personal_memory`、端口号） |

候选对比过的字体：站酷庆科黄油体（太圆润卡通）、马善政毛笔体（太书法）、Zen Antique / Shippori Mincho / BIZ UD Mincho（日文字体，缺大量简体字，淘汰）。全部离线内置 woff2，`scripts/build-fonts.py` 重新生成。

## 二、版式规则
- 去掉：细框、胶囊、下划线标签、一行一行带分隔线的列表、左边框强调条、竖排标签下的细线。
- 改用：字号/字重对比、留白、橙色辉光点、局部渐变色块（选中项/层级面板）、章节竖排小标题 + 辉光数字编号。
- 文字背后：`.col::before` 局部径向渐变垫底，保证在亮底图上可读；路线章单独垫底。
- 双模式：两个大字并排，选中放大 + 橙色辉光 + 柔光斑滑动，未选中缩小变暗（`transform` + `text-shadow` 过渡），不再是细框标签。

## 三、逐章“原文案 → 新文案”
**01 序**
- 标题：她在你的 / 本地世界线上 → **她住在你的 / 本地世界线**
- 副标：牧濑红莉栖 · AI 陪伴应用（不变）
- 三项：本地优先 · 单用户 · 自行配置 → **数据留在本机 ／ 只有你与她 ／ 凭据自己填**

**02 定位**（标题不变：不是托管服务，是你机器上的她。）
- 本地优先：前端、网关与服务，都运行在你的机器上。→ **前端、网关、服务，都跑在你的机器上。**
- 单用户：不做 SaaS，只有“你”与她这一种关系。→ **不做 SaaS。只有你，和她。**
- 自行配置：不附带模型服务、共享密钥或免费额度。→ **不送模型额度，也不附共享密钥。**

**03 双模式**
- 标题：两种模式，同一个她。→ **两种玩法，同一个她。**
- 日常陪伴：流式回复，无语音也能独立工作 → **流式回复，没有语音也能用**；识别文字可见，开口即可打断她 → **说话就能打断她，识别的字看得见**；只记偏好与重要事件，失败不阻塞 → **只记偏好和要紧的事，记不住也不卡住**；中文字幕始终可见 → **中文字幕一直在**
- VN 陪玩：你选定窗口，她只描述看到了什么 → **你选窗口，她只说看到了什么**；该不该开口，由她判断；沉默也是回应 → **开不开口由她定，沉默也算回应**；字幕、语音与形象同步表演 → **字幕、语音、动作出自同一份计划**；点击与选择仍由你完成 → **点击和选择，始终是你的**
- 备注：设计目标 · 开发中 → **VN 陪玩 · 设计目标，开发中**

**04 边界**
- 导语：运行时，她可用的信息分成四层，禁止混用。→ **她能用的信息分四层，不能混着用。**
- 确定的个人记忆：亲历、明确知道，或对话中已确认的事实。可以直接陈述。→ **亲历的、明确知道的、对话里确认过的。可以直说。**
- 当前观察：基于画面证据：你选定的窗口里“看到”了什么。可以说“我看到”。→ **来自你选的窗口：她看到了什么，就说“我看到”。**
- 碎片既视感：只能用不确定的表达，如“好像……”“有点熟悉”，不下断言。→ **只能含糊地说，“好像……”“有点眼熟”，不下断言。**
- 禁止全知：不得当作角色知识使用：作品外信息、未解锁的剧情与结局。→ **作品外的信息、没解锁的剧情和结局，不能当她的知识。**
- 备注：对 Re:Boot 的新剧情，她一无所知。→ **Re:Boot 的新剧情，她一无所知。**

**05 表演**
- 说明：三路由同一份 CharacterPerformanceEvent 驱动，避免各说各话。→ **三路出自同一个 CharacterPerformanceEvent，不会各说各话。**
- 字幕：始终可见 → **一直看得见**

**06 本地**
- 密钥与私有资产不入库 → **密钥和私有素材不入库**
- 采集可见、可随时停止（设计目标）→ **采集看得见，随时能停（设计目标）**

**07 路线**
- 结构：“阶段 0–6.25 · 基础”拆成小标注（阶段）+ 大标题（基础），避免窄栏折行
- 本地对话、角色、记忆、文本与语音、屏幕采集 → **对话、角色、记忆、文字与语音、屏幕采集**
- 发售后对齐真实 UI、术语与章节 → **发售后，对齐真实 UI 与术语**
- 备注：课堂展示用宣传页：交互均为示意，不含任何用户规模或性能数据。→ **课堂展示页：交互只是示意，没有任何用户规模或性能数据。**

**08 终**
