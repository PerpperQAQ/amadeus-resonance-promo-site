## 2. 用户项目的开场时间线（实测）

约 5 s，暗场 → 首屏入口：
1. **0–0.3 s**：黑底，红莉栖近景 CG 压暗淡入，画面上叠**横向红橙色光带**（6 条细线，缓慢左右漂移）。
2. **0.3–2.3 s**：**满屏巨大的辉光管读数**（8 位，宽度几乎占满屏幕，细线字形，橙红 + 外发光）整排成组跳变，约 250 ms 一次：`1.130426 → 3.352468 → 0.029135 → 7.776802 → 9.578024 → 0.571024 → 1.354620 …`；跳变帧带轻微色散；背景夹杂方程/二进制字符串。
3. **约 1.2–3.5 s**：**一束世界线**从屏幕上方汇向**左下角**，再沿**底边向右生长**（许多极细的线 + 流动光点 + 红色微粒），生长到右侧；底边线最终固定为一条白色细曲线。
4. **约 2.0–3.4 s**：读数**逐位锁定**到 `1.048596`（每位约 110–150 ms，锁定位亮度提升、未锁定位继续乱跳），最后一位落定时有一次小闪。
5. **约 3.6–4.2 s**：读数淡出，只剩底边世界线；左上角出现 Amadeus logo；入口出现 `EL.PSY.KONGROO`。
6. **Ready 入口**：悬停“接入”时底部文字由 **IBM 5100 风格的 APL 乱码**（`⍴⍳∊∆∇⎕⍞○…`、下划线大写、数字）**逐位跳动并锁定成 `EL.PSY.KONGROO`**；非悬停时是一串 APL 乱码。
7. **Enter → Daily 转场**：画面整体压暗淡出（镜头拉远感），然后在日常场景里角色淡入，辉光管读数缩成左上角小件。

**转场语言**：硬切 + 色散闪、整排数字跳变、线束生长、淡入淡出；几乎没有“平滑缓动的卡片滑入”。**配色**：黑 + 橙红 + 少量暖白；红色光带是关键的“危险/世界线”信号。

## 5. 实看视频关键帧（第四轮）

用户提供了原作片段《【命运石之门片段】世界线六次变动片段截取.mp4》（1280×720，约 8 分钟）。先由视频模型生成了一份分析（`/workspace/worldline-video-analysis.md`），我再用 ffmpeg 在 Mac 上按其时间点（00:04–00:12、00:22–00:32、00:40–00:47、00:53–00:59、01:10–01:15、01:21–01:28）每 0.25 s 抽帧到项目 `.tmp/wl-frames/`（**仅本地工作文件，不进工程交付/dist**），并亲自看了 6 张联系表（`sheet1–6.jpg`）与 3 张放大帧。结论以实看为准：

**与模型分析一致的**
- 触发：手机（红色翻盖/发送完成）特写 → **白光过曝**把画面吞没；之后是人物近景的**去饱和/偏青绿的反相色**、强烈模糊与拖影（烟雾般的重影），第 3 次出现闪电与**人物液化扭曲**，第 5 次**极度推近到瞳孔**、数字叠在瞳孔上，第 6 次出现“融化”与噪点。
- **蓝色交织正弦（示波器）波纹**确实存在，叠在深蓝/黑底和模糊人影上，第 1、2、3、6 次明显，第 5 次没有。
- 辉光管：8 位、固定小数点、**橙红偏亮黄的细线字形**、金属网格底板、玻璃管边；数值**随机快速跳变**（如 1.905006 → 0.805871 → 1.609757…），带**强烈散焦/横向与纵向动态模糊 + 重影**；最后**卡定**在目标值（0.571024 / 0.571015 / 0.523299 / 0.409420 / 0.337187）。落定后下一帧是**横向拖影的橙色光带**，随后**硬切黑场**。
- 视频上方橙色“世界线变动率：a→b”字幕是搬运者加的，非原作画面（本页不使用）。

**需要修正的（实看不同）**
1. **白场不是“0.1 s 内闪一下”**，而是约 1–1.5 s 的**持续过曝洗白**（画面逐渐被白光吞掉、人物发白），并非高频硬闪（高频黑白闪仅在第 4 次）。
2. **蓝色波纹不是主体**，只是辉光管出现前约 0.5–1 s 的“过门”；多数时间是**去饱和的模糊场景 + 噪点**，辉光管数字是叠在这个模糊场景上的（并非总在纯黑背景上）；纯黑底只出现在卡定之后。
3. 辉光管**一开始很大、很糊（散焦）**，随后变清晰；各位**几乎同时卡定**（不是严格从左到右）。落定后有短暂的发光峰值，然后被横向拖影吞掉。
4. “垂直老虎机式滚动”不太准确：看到的主要是**数值整体随机跳变 + 运动模糊**，不是每位竖向滚动条。
5. 没有时钟/齿轮元素（与模型分析一致）；本页 logo 齿轮保持原有设计，不在世界线变动里使用。

**据此的实现（`src/shift.js`、`src/waves.js`、`src/tube.js`）**
`叮 + 门灯闪` → 白场过曝洗白(≈0.45 s，文字在白光里崩成 IBM 5100 乱码) → 白光退去，**偏青负片闪烁 + RGB 色散 + 液化扭曲(SVG feDisplacementMap) + 镜头抖动** → **深蓝黑异空间 + 交织蓝色正弦示波器波纹**，IBM 5100 屏幕亮起解码 → **8 位辉光管**从散焦放大逐渐清晰，高速随机跳变（模糊/重影），约 2 s 后逐位卡定、亮度峰值 → **横向拖影闪过 → 黑场硬切**，此刻换世界线配色/背景/人物模型 → 黑场淡出，文字逐行从乱码重组。世界线进度条、开屏也采用同一语言：**蓝色交织正弦线束 + 一条琥珀亮线**，辉光管用橙红/亮黄芯 + 玻璃管 + 金属网格。限制：这是对原作演出的**风格致敬**，不是逐帧复刻；没有使用原作视频帧作为素材。

### 6.2 辉光管（`src/tube.js` / `src/meter.js`，开屏、变动、结尾共用）
- 七位读数 = 1 位整数 + 6 位小数，**小数点单独占一个管位**，共 8 个管位；
- 数字是**弯曲细线轮廓**：亮芯浅橙/杏黄，近晕橙，外晕橙红；灰白玻璃壳只在部分阶段清晰（锁定后 `clear`）；
- **整组一起跳**：每个“镜头”（read/blur/gap/big）持续 42/83/125ms，read 常只有 1–2 帧，中间夹失焦、放大、缺席（gap 时被人像/符号/噪点遮住）；不做逐位停转、不做竖向滚动；
- 最终值成立后保持 ≥0.4s，管组此后仍可位移/缩放/失焦（锁定帧 `scale 1.03`，随后收成细横线）；
- **统一时间轴**：没有任何逐位计时器，`Meter.tick(now)` 由开屏循环 / 变动演出的同一个 rAF 驱动。

### 6.3 变动转场时间线（按第二次 28.125–32.167s，网页约 4.0s）
| 时间 | 实现（`shift.js` 阶段名） |
|---|---|
| 0.0–0.3s | `burst`：横向冲模糊（SVG `feGaussianBlur 16 0`）+ 左右错位的多层残影（drop-shadow）+ 镜头抖动；全页文字开始崩成 IBM 5100 乱码 |
| 0.3–0.8s | `teal`：青绿高亮（hue-rotate+亮度）→ 短暂回暖 → `dark`：异常暗色与颗粒（noise 层） |
| 0.8–1.0s | `vstretch`：竖向拖糊（`feGaussianBlur 0 18`） |
| 1.0–1.4s | `cyan`：约 83ms 黑帧 → 蓝青单色人影 + 浅青底上的深蓝交叉长波（`Scope`，深蓝细线） |
| 1.4–3.2s | `tubes`：橙色整组乱数，与灰白人像、APL 符号蒙太奇（`.sh-mont`）、噪点交替；管组比例/位置/锐度随机；IBM 5100 屏幕同时解码 |
| 3.2–3.6s | `lock`：最终值完整成立，玻璃管清楚（若模型尚未换好则等待，不会提前落值） |
| 3.6–4.0s | `fade`：管组收成橙色细横线 → 黑场；此刻换世界线配色/文案/人物模型 → `reveal`：黑场淡出，文字逐行从乱码重组 |

四种变体轮换，不套同一动画：① 标准；② 液化扭曲 + 前段多次闪白（闪电感）；③ 推近到眼睛（页面缩放到人物面部，辉光管以 screen 混合叠在瞳孔位置；人物保持可见到最后）；④ 前段失稳延长 1.6 倍。六次落值参考：0.571024、0.571015、0.523299、0.456903、0.409420、0.337187；本页只有两个世界线（A 1.048596 / B 0.571024），“眼睛/倒影”变体是对第五次的**近似**，没有逐帧复刻瞳孔倒影。
